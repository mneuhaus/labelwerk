Print labels. No detours.

Labelwerk is a lean app for Brother label printers of the QL and PT series. Type the text, see the label at real size, print. No P‑touch Editor, no driver, open source. For macOS and Windows.

Features

Everything a label needs. Nothing more.

One window, one text field, one preview. Labelwerk reads which printer is connected and which tape is loaded, and sets itself up for it.

Preview at real size

The label lies on a centimetre grid, with its length and cut edges. What you see is the layout that gets printed. "Print dots" shows the actual dots of the print head.

Type that fits

Size automatically as big as it fits, or fixed in pt. First line as a heading, bold, italic, alignment, bundled Barlow or any system font.

The printer speaks up

Model, tape width, tape colour and errors such as "cover open" or "no tape loaded" come straight from the device. The preview shows the label in the real tape colour.

Tape and labels

Length follows the text or is fixed in mm. Text along or across the tape with ⌘R / Ctrl+R. Die-cut and round QL labels work too.

QR code and frame

A QR code with the label text or your own content, plus frame and margin. One click, no dialog.

Reprint in one click

Recently printed labels sit at the bottom as thumbnails. ⌘P / Ctrl+P prints, the number of copies is right next to it.

Install

Printing in two minutes

  1. macOS: Labelwerk-0.1.0-alpha.2-macos.zip, unzip, move to Applications. The app is not notarized yet: on first start click "Open Anyway" under System Settings → Privacy & Security, or run
    xattr -dr com.apple.quarantine /Applications/Labelwerk.app
  2. Windows: Labelwerk-0.1.0-alpha.2-windows-x64.zip, unzip, start Labelwerk.exe. It is not code-signed yet: if SmartScreen warns, choose "More info" → "Run anyway".
  3. Connect the printer over USB and switch it on. No Brother driver needed. On a PT-P710BT or PT-P750W, Editor Lite must be off (LED dark).

Alpha means: it prints, but things are missing (network and Bluetooth, images, barcodes other than QR), and Windows printing still needs reports from real hardware. The interface is English, or German on German systems. All versions: Releases.

Command line
# connected printer and loaded tape
labelwerk status
# print a label, three copies
labelwerk print -t "M3 screws" --copies 3
# preview as PNG
labelwerk render -t "Cable\nHDMI" --bold -o preview.png
# all models, all tapes of one model
labelwerk models
labelwerk media --model PT-P710BT

The CLI ships as labelwerk-cli-… in every release. --json gives machine-readable output.
